# Tarun R — AI & ML Infrastructure Command Center & Portfolio Suite

A multi-experience portfolio suite featuring **4 MotionSites AI design styles** plus an interactive **2D Cyberpunk RPG Game Mode**, showcasing engineering projects, localized LLM systems, and LangGraph agentic architectures.

🌐 **Live Site:** [iam-tarun-86-.github.io/tarun-portfolio](https://iam-tarun-86-.github.io/tarun-portfolio)

---

## 🎨 5 Integrated Design Experiences & Live Switcher

Visitors can toggle seamlessly between all 5 modes via the floating bottom dock:

1. 💎 **Finlytic AI Agent** — Liquid-glass morphism, violet/cyan glow bento grid, interactive prompt inference sandbox.
2. ⚡ **Digital Epoch** — Cyber-grid backdrop, infinite smooth marquee ticker, high-contrast engineering badges, floating HUD.
3. 🛡️ **AKOR Security** — Mission-control SIEM dashboard with an interactive 3-node LangGraph DAG threat simulator (`Ingest ➔ Classify ➔ Route`).
4. 🔥 **EMBER / Lumina** — Deep luxury obsidian aesthetic, ambient spotlight glow, and clean architectural case studies.
5. 🎮 **Cyberpunk Game Mode** — Interactive 2D top-down arcade laboratory where visitors navigate with `WASD` / Arrow keys (or mobile touch joystick) to collect GGUF Quantization Shards and interact with project/skill pods!

## 🛠️ Key Technical Features

- **Interactive 3-Node LangGraph DAG Simulator:** Live visualizer simulating forensic threat evaluation (SSH brute force, SQL injection, benign ping) across `Ingest`, `llama.cpp Quantized Classifier`, and `FastAPI Action Router`.
- **Pro Developer CLI:** Interactive terminal supporting Tab-autocomplete, Up/Down command history, Matrix rain mode, in-browser matrix tensor benchmarking (`bench`), and resume downloads.
- **Procedural Web Audio Engine:** 100% code-generated audio effects using the Web Audio API (keystrokes, sweeps, retro 8-bit game beeps, laser pulses) with zero external media files.
- **Dynamic Adaptive Background Canvas:** Real-time particle physics, radar sweep cones, and matrix streams that adapt to the active theme.
- **Live GitHub Telemetry:** Dynamically fetches public repository and contribution metrics from the GitHub REST API.
